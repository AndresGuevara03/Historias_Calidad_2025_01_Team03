# Historias_Calidad_2025_01_Team03

# Historia Calidad 1

*Prioridad:* Alta

- *Cuando:* Un estudiante accede a un simulador o calculadora desde cualquier dispositivo.

- *Dado que:* El sistema está en operación normal.

- *Yo como:* Estudiante.

- *Quiero:* Que la plataforma tenga un diseño responsivo y adaptado a distintos tamaños de pantalla.

- *Y debe suceder:* Que los simuladores y calculadoras sean completamente funcionales tanto en computadoras como en dispositivos móviles y tablets sin afectar su usabilidad.

# Historia 2: Disponibilidad  de Recursos Didácticos sin Interrupciones

*Prioridad:* Alta

*Cuando:* Un profesor sube un nuevo recurso didáctico (simulador o calculadora).

*Dado que:* El sistema está en operación normal.

*Yo como:* Profesor.

*Quiero:* Que la plataforma garantice la disponibilidad del recurso sin tiempos de inactividad.

*Y debe suceder:* Que el nuevo recurso esté disponible inmediatamente después de su carga, sin afectar el acceso a los recursos existentes.

# Historia 3

**Prioridad: Media**

**Cuando:** Un usuario intenta acceder a la plataforma en un horario de alta demanda.
Dado que: El sistema está en operación normal.
Yo como: Administrador del sistema.  

**Quiero:**  Que el sistema escale automáticamente para manejar la carga.  

**Y debe suceder:** Que la plataforma pueda soportar al menos 500 usuarios concurrentes sin degradación en el rendimiento y con tiempos de respuesta menores a 3 segundos.

# Historia de Calidad 4: Validación de datos 

- *Prioridad*: Media

- *Cuando*: Un usuario introduce datos en un formulario y envía la información.

- *Dado que*: El sistema está en operación normal.

- *Yo como*: Usuario del sistema.

- *Quiero*: Que el sistema valide la información ingresada antes de enviarla al servidor.

- *Y debe suceder*: Que se muestren mensajes de error en tiempo real si hay datos incorrectos o incompletos, evitando envíos innecesarios al servidor.

# Historia de Calidad 5: Reportes del uso de los recursos

- *Prioridad*: Alta

- *Cuando*: Un profesor o estudiante consulta estadísticas sobre el uso de los recursos.

- *Dado que*: El sistema está en operación normal.

- *Yo como*: Administrador del sistema.

- *Quiero*: Que la plataforma genere reportes y métricas de uso de manera eficiente.

- *Y debe suceder*: Que los reportes se generen y sean accesibles sin afectar el rendimiento general del sistema.


## Historia 6 (Seguridad y Control de Accesos)

Prioridad: Alta

Cuando: Un usuario intenta acceder a un recurso para el cual no tiene permisos.

Dado que: El sistema está en operación normal.

Yo como: Administrador del sistema.

Quiero: Que los permisos y roles de usuario estén correctamente implementados.

Y debe suceder: Que el sistema restrinja el acceso y registre intentos fallidos en un log de auditoría.

## Historia 7 (Monitoreo y Mantenimiento)

Prioridad: Media

Cuando: Se produce una caída en algún servicio del sistema.

Dado que: El sistema está en operación normal.

Yo como: Administrador del sistema.

Quiero: Que el sistema detecte problemas en tiempo real y los notifique automáticamente.

Y debe suceder: Que se envíen alertas a los administradores mediante correo electrónico o mensajería instantánea cuando ocurra una falla crítica.git status 

## Historia 8 (Registro y Análisis de Datos)

- **Prioridad:** Media

- **Cuando:** Se necesita evaluar el uso de los recursos educativos en la plataforma.

- **Dado que:** El sistema está en operación normal.

- **Yo como:** Coordinador académico.

- **Quiero:** Que la plataforma genere informes detallados sobre la actividad de los usuarios.

- **Y debe suceder:** Que se pueda acceder a reportes con métricas de uso, tiempos de interacción y tendencias de aprendizaje.
